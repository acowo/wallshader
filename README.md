# wallshader

wallshader (working title) is intended to be a wallpaper program for Hyprland (presumably with support on Wayland compositors) that draws a live, procedurally generated wallpaper using Vulkan.

## Scope

The project will have testing and reporting of GPU utilization.

## Known issues

The window doesn't show when initially creating (per commit 0b60360), presumably a quirk of Wayland.
